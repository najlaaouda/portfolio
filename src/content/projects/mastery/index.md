## Overview
MasteryAcademy is a training platform. Its B2B dashboard lets a company's admins and supervisors run learning for their employees: assign courses and learning paths, schedule live sessions, follow everyone's progress and report on it. I designed the dashboard as the UX/UI designer, in Arabic and right-to-left, for desktop, tablet and mobile, in light and dark mode.

## The challenge
Admins need to manage a lot at once: people, groups, courses, learning lists, learning paths, live sessions, notifications and reports. The dashboard had to keep all of this findable without overwhelming them, and present dense data such as tables, charts and calendars clearly in Arabic.

## Information architecture
The sidebar groups everything into three areas:

- **General**: Overview, Users, Groups, Learning paths, Learning lists, Requests and Reports
- **Communication centre**: Notifications
- **Library**: Training courses

A **Quick create** button stays at the top of the sidebar, so the most common actions are always one click away. The sidebar collapses to icons to give tables more room.

## Design decisions
**An overview the admin can shape.** The quick summary shows eight key numbers, and "Customise statistic" lets each admin choose which ones matter to them.

**Tables built for real work.** Every list has search, filters, a date range, column customisation, bulk selection and Excel export, so admins can answer their own questions without asking for a report.

**Two ways to see live courses.** The same schedule can be viewed as a table or as a yearly calendar, with each course card showing its dates, duration and trainer.

**Preview before sending.** When writing a notification, the admin sees exactly how it will appear by email, inside the platform and as a push notification.

**One system, every screen.** Light and dark mode, and the tablet and mobile layouts, are built from the same components and tokens, so the experience stays consistent across devices.
